# GitHub Free compatibility audit

2026-11-01; personal private repository; actual account subscription/budget not independently checked. Official documentation below is a planning snapshot, subject to change. This design does not require Pro/Team/Enterprise; however manual review is not equivalent to enforceable private branch protection.

| Feature | GitHub Free availability | Limits | Paid requirement | Alternative |
|---|---|---|---|---|
| Public/private repositories and collaborators | Unlimited both, personal account | Private features limited; personal collaborators have broad permissions | No | Minimal collaborator access; manual controls |
| PR and code review | PRs/review available | Required reviews and multiple reviewers for private personal repos limited | Pro for those private features | Manual named reviewer, owner merge after evidence |
| Branch protection/rulesets | Public yes; private personal Free not included | GitHub reports main unprotected; rulesets not checked | Pro for private branch rules/rulesets; push rulesets have additional plan restrictions | Owner-only merge, no force push, manual checklist; cannot technically enforce |
| Actions | Standard public runners free; private included compute **$12/month** | At $0.006/min Linux approximately 2,000 minutes if entire credit used there; other runner rates and cloud usage draw credit; 500 MB shared artifacts/packages storage, 10 GB cache/repo | Overage may bill if enabled | Local checks, short Linux workflow, cancel duplicates; no change to billing |
| Packages | Public free; private included | 500 MB shared storage, 1 GB transfer/month; Actions storage shares allowance | Overage possible | npm public, no private packages |
| Dependabot | Alerts and security updates available for public/private | Check current settings; PRs still need review | No | `corepack pnpm audit` |
| Code scanning / user secret alerts | Public free; private personal Free does not include full Code Security/Secret Protection | Availability varies by repository ownership and product | Paid organization licenses for private advanced products; do not assume personal Pro supplies them | Local open-source Semgrep/Gitleaks and dependency audit; do not leak scan output |
| Pages | Public repo supported | Private repo Pages not on Free | Pro for private-repository Pages feature; private publication has further restrictions | Existing approved hosting, no Pages needed |
| Codespaces | Personal Free | 120 core-hours and 15 GB-month monthly; machine cores multiply hours | Overage if billing configured | Local environment |
| REST API | Yes | 60 unauthenticated requests/hour, typically 5,000 authenticated/hour; separate secondary limits and GraphQL | No | Cache, paginate, conditional requests |
| Releases | Yes | Up to 1,000 assets/release, each <2 GiB; no total release size/bandwidth cap per docs | No | Explicit approved release only |
| Workflow artifacts | Yes | 500 MB shared quota; retention and size subject to policies | Overage possible | Short retention, avoid binary artifacts until approval |

Current repository evidence: `main` protected=false, seven open PRs conflicting, latest main CI failed typecheck; do not assume free allowance means workflows are green. Manual native workflow produces APK/AAB: do not dispatch without release/build approval. No publicizing a private repository as a security workaround without explicit approval.
