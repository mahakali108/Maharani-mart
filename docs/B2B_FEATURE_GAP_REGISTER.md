## Existing capabilities deliberately preserved, not release-certified

Inspected code includes district-aware service areas, one active warehouse resolution, Maharani stock/pack availability, MOQ and server pricing, coins, authentication, catalogue/cart/orders, retailer/support/admin workflows, and a **native Kotlin/Jetpack Compose** Android module. This audit did not replace it with WebView/PWA/Capacitor, invent inventory, add a seller, alter stored totals or erase data. The worktree's safety holds intentionally interrupt **coupon reuse, failed-delivery re-dispatch and KYC deletion** until evidence-preserving designs are approved. The existence of routes/components/migrations is not proof they work or are legally sufficient in a deployment.

## Exit policy

Close a row only with an owner-named decision, evidence link/artefact, dated lawyer/CA sign-off if relevant, merged code/schema review **on the authorized branch**, recorded isolated tests, and explicit production rollout/rollback authorization. `0059` is a reversible proposal; no migration was applied under the current instruction. Do not interpret a green source-only test as proof of RLS, SQL execution or a production hold.
